# Polygon Beater Cinema

An independent archive of in-depth film essays, visual analyses, and historical cinema explorations created by Vítězslav Koneval.

- **Author:** Vítězslav Koneval (Polygon Beater)

## About the Project
Polygon Beater Cinema is a bilingual (Czech / English) platform dedicated to exploring classic cinema, film noir, auteur theory, and the visual arts through carefully crafted essays and study materials.

## Technology Stack
- **Framework:** [Astro](https://astro.build) (Static Site Generation)
- **Content Management:** Markdown (`src/content/essays/`)
- **Deployment:** GitHub Pages
